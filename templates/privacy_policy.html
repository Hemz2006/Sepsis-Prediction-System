Privacy Policy

This Privacy Policy explains how the Sepsis Prediction Simulator ("the Service") handles information. This application is a demonstration / academic tool and is not a production medical system. By using the Service you acknowledge the demo nature of the platform.

What data we collect

  • Basic usage data (e.g., timestamps, page visits) for analytics and improvement.
  • Clinical inputs you provide when using calculators or adding patient/demo records (vital signs, laboratory values). In demo mode these inputs may be stored locally in the instance database for demonstration and testing.

How we use data

  • To provide risk calculations and assessment results as part of the demo feature set.
  • To improve the application, fix bugs, and for educational or research analyses (aggregated, de-identified).
  • To demonstrate workflows and functionality for clinicians and developers.

Data security and privacy practices

We follow reasonable practices for a demonstration application. This project is provided for educational purposes; if you deploy this project in a production environment you must configure secure hosting, encryption at rest and in transit, access controls, and compliance with relevant regulations (e.g., HIPAA) before using real patient data.

Disclaimer

This tool is a demo/academic project and not intended to be used as a medical device or substitute for clinical judgment. Results are provided for demonstration and educational purposes only.

Contact

For questions or support related to privacy, please contact: support@example.org.
